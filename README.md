# 🦉 Mingo — Aprenda inglês de um jeito divertido!

**Mingo** é uma plataforma web desenvolvida para tornar o aprendizado de inglês mais divertido, acessível e interativo.

A proposta é transformar o estudo em uma experiência dinâmica, na qual você pode testar seus conhecimentos, enfrentar desafios e acompanhar sua evolução enquanto aprende.

> Aprender inglês não precisa ser complicado. Pratique, desafie-se e evolua com o Mingo!

---

## 🎨 Design

O projeto conta com uma identidade visual própria, desenvolvida no Figma, buscando uma interface amigável, intuitiva e inspirada em plataformas modernas de aprendizado.

## 🚀 Funcionalidades

- **Quizzes interativos:** pratique inglês respondendo a perguntas de múltipla escolha.
- **Três níveis de dificuldade:** escolha entre Fácil, Médio e Difícil.
- **Perguntas aleatórias:** cada partida apresenta uma seleção aleatória de questões.
- **Resultados instantâneos:** confira seu desempenho ao finalizar uma atividade.
- **Histórico de partidas:** acompanhe seus resultados e veja sua evolução.
- **Interface responsiva:** experiência adaptável a diferentes tamanhos de tela.

## 💻 Como executar o projeto

### Pré-requisitos

Antes de começar, você precisará ter instalado:

- [Node.js](https://nodejs.org/)
- [Angular CLI](https://angular.dev/tools/cli)

### Instalação

**1. Clone o repositório:**

```bash
git clone https://github.com/PlopesK/Mingo.git
```

**2. Acesse a pasta do projeto:**

```bash
cd Mingo
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Inicie o servidor de desenvolvimento:**

```bash
ng serve
```

**5. Acesse a aplicação no navegador:**

```text
http://localhost:4200/
```

## 🔒 Privacidade e armazenamento

O Mingo não exige criação de conta ou autenticação para utilizar suas atividades.

O histórico de partidas é armazenado localmente no navegador por meio do `localStorage`, permitindo consultar resultados anteriores no mesmo dispositivo e navegador.

## 🎓 Sobre o projeto

O **Mingo** foi desenvolvido como parte de uma atividade extensionista do curso de Ciência da Computação da **UNINTER**, com o objetivo de aplicar conhecimentos de tecnologia no desenvolvimento de uma solução educacional.

A proposta surgiu da ideia de criar uma plataforma acessível e interativa que incentivasse o aprendizado da língua inglesa por meio de desafios e atividades práticas.

O projeto foi desenvolvido em colaboração entre **Gabriel Primo** e **Rodrigo Rabuske**, reunindo esforços para transformar a ideia em uma aplicação funcional.
